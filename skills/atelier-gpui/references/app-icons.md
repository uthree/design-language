# App icons and logos

An Atelier app's icon is an element cell: **two letters, a capital and a lowercase, on a dark
tile tinted in the app's element colour**, with the app's register number in the top-left
corner. Auris Studio is **Au** (gold, number 1). The full guide, with images, is
`doc/app-icons.md` in the Atelier repository; this page is what you need to make or review one.

## Choosing the symbol

1. One capital and one lowercase letter (`Au`, never `AU`, `au` or `A`).
2. From the app's distinctive word: drop Studio, App, Pro, Lab, Desktop, Suite, Tool. One word →
   its first two letters (Auris → Au); two words → the initials (Node Editor → Ne); on a
   collision → first letter and next consonant (Plot → Pt).
3. Unique in the suite. Reject pairs that blur at 16 px (`Il`, `Ii`, `Ij`, `Ll`, `Rn`, `Cl`,
   `Vv`, `Ww`) and pairs that are interface words (`Ok`, `No`, `Go`, `On`, `Up`).
4. If the symbol is a real element, choose the colour that agrees with it (Au → gold,
   Ag → graphite).
5. Auris Studio's family form **As** (family initial + product initial) is used only once a
   second Auris product ships, and then for every product at once.

## Never draw it by hand

Add the app to `tools/app-icon/apps.toml` (slug, name, symbol, the next unused number, an
element colour, `ship = true`) and run `python3 tools/app-icon/make_icons.py`. It writes
`assets/app-icons/<slug>/`: `icon.svg` (+ `-medium`, `-small`), `icon-macos.svg`, `icon.icns`,
`icon.ico`, `png/16…1024.png`, `icon-metal.svg` and `symbolic.svg`. Construction (superellipse
tile, Inter Display Bold at cap height 0.36 of the tile, 7:1 glyph contrast, Glass sheen and
rim, per-size detail) lives in the tool; change it there and in the guide together.

Element colours: gold, orange, crimson, rose, violet, blue, cyan, seaglass, green, lime,
graphite (hues of `BackdropPalette`). **Never the agent gradient**: inside Atelier it means "the
AI", so an icon in it would say the whole app is the agent.

## In the app

- Ship the generated files: `.icns` for the macOS bundle, `.ico` for the Windows executable,
  `png/<size>.png` and `icon.svg` for Linux `hicolor`, `symbolic.svg` for a tray or menu bar.
- Beside the app's name (About, welcome card, title of a chooser) use the image at the name's
  line height, `spacing.sm` from it. Do not set the two letters as text.
- The metal finish (`icon-metal.svg`) is for hero uses at 256 px and up only, never the dock,
  taskbar or file lists.
- Never recolour, outline, stretch or re-tile the mark; never set it on the metal or an ambient
  scene, only on a card above it.

## Review checklist

- [ ] Symbol follows the rules above and is unique in the suite.
- [ ] Generated by the tool; `png/16.png` legible on light and dark desktops.
- [ ] Element colour from the list, not the agent gradient, not a neighbour's.
- [ ] All platform files present and wired into the build (bundle, executable resource, desktop entry).
